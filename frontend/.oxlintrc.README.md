# Lint configuration notes

`jsx-a11y` is on, because accessibility problems are much cheaper to catch here
than in the Playwright axe suite.

Three of its rules are deliberately off:

- **`prefer-tag-over-role`** — stylistic. It wants `<output>` instead of
  `role="status"` and so on. The existing roles are correct and pass axe; this
  produced 39 warnings and no real findings.
- **`no-noninteractive-element-to-interactive-role`** — the search box's
  type-ahead is a `listbox`/`option` combobox built the way the ARIA authoring
  practices describe. The rule cannot tell that apart from a misuse.
- **`label-has-associated-control`** — false positive in
  `PaymentMethodPicker.jsx`, where the `<label>` wraps both the radio and its
  text. That is valid and accessible; the rule cannot see through the dynamic
  label content.

The real accessibility guarantee is `e2e/a11y.spec.js`, which runs axe over the
main pages at desktop and mobile widths. These lint rules are the fast first
pass, not the whole story.
